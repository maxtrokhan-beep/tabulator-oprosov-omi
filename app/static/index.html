MVP Табулятор маркетинговых опросов
Загрузите Excel/CSV, настройте переменные, постройте кросс-таблицы и скачайте Excel.

Загрузка базы

Формат: 1-я строка = тех. имена, 2-я = текст вопроса, 3-я пустая, с 4-й ответы. Поддержка: .xlsx / .csv. Если есть колонка weight, станет доступна взвешенная табуляция.

Настройка переменных

Отметьте тип переменной. Для множественного выбора — объедините несколько колонок в один вопрос (например, Q5_1..Q5_3 → Q5).
