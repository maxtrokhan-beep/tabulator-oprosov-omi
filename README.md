# MVP онлайн-табулятор для маркетинговых опросов (FastAPI + pandas)

Простой веб‑табулятор без логина и базы данных:

- загрузка `.xlsx` или `.csv`
- экран настройки переменных (типы, шкалы, Top‑2 box, объединение колонок в множественный выбор)
- построение кросс‑таблиц (проценты по колонке, база ответивших)
- взвешенные расчёты, если есть колонка `weight`
- опциональная статистическая значимость (90%): z‑test для процентов, t‑test для средних
- экспорт результата в Excel

Интерфейс: русский. Дизайн: простой и функциональный.

## 1) Установка зависимостей

Требуется Python 3.10+ (рекомендуется 3.11).

В PowerShell (Windows):

```powershell
cd .\mvp-tabulator\
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## 2) Запуск локально

```powershell
cd .\mvp-tabulator\
.\.venv\Scripts\Activate.ps1
uvicorn app.main:app --reload
```

Откройте в браузере:

- `http://127.0.0.1:8000/`

## 3) Как пользоваться (коротко)

1. Вкладка **1) Загрузка** → загрузите `.xlsx` или `.csv`.
2. Вкладка **2) Настройка переменных**:
   - выставьте типы (категориальная / шкальная / служебная)
   - для шкал нажмите **«Шкала/Top‑2»** и задайте коды + правило Top‑2
   - для множественного выбора: задайте имя группы (например `Q5`), выберите колонки (`Q5_1`, `Q5_2`, …) и нажмите **«Добавить группу»**
   - нажмите **«Сохранить настройки»**
3. Вкладка **3) Табуляция**:
   - выберите вопросы в строки
   - выберите баннеры (можно несколько — колонки будут вложенными)
   - добавьте фильтры при необходимости
   - нажмите **«Построить…»**, затем **«Скачать Excel»**

## 5) Деплой на Render

В проекте уже есть `render.yaml`, поэтому самый простой путь:

1. Зайдите в Render → **New** → **Blueprint**.
2. Выберите ваш GitHub репозиторий.
3. Render сам прочитает `render.yaml` и создаст сервис.
4. После деплоя откройте URL сервиса — это будет ваш табулятор.

Если Render попросит команды вручную:

- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`

## Важные примечания по методологии (как реализовано в MVP)

- Проценты считаются **по колонке** (внутри каждого столбца баннера).
- Абсолюты в таблице не показываются; база показывается отдельной строкой.
- Взвешивание:
  - проценты и средние считаются с весами `weight`
  - база при взвешивании — сумма весов
- Статистические тесты (если включены) считаются только при базе \(\ge 30\).
- Для взвешенных тестов используется **эффективная база Kish**:
  \[
  n_{eff} = (\sum w)^2 / \sum(w^2)
  \]
  Это аккуратное приближение для MVP; подробности вынесены в код (`app/core/tabulator.py`).
